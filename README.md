# leadership-platform-v2

نسخة من «منصة التواصل القيادي» تقرأ بياناتها من قاعدة بيانات Supabase بدل أن تكون مكتوبة داخل الكود.

**التصميم والحسابات وكل منطق العرض هنا مأخوذ حرفياً (بلا أي تعديل) من `index.html` المعتمد.**
الشيء الوحيد الجديد فعلياً هو `lib/fetchData.js` — طبقة تقرأ من Supabase وتُعيد بناء نفس أشكال
البيانات التي كان يقرأها الكود القديم من متغيرات ثابتة.

## قبل النشر على Vercel

هذا المشروع يحتاج إلى متغيرين بيئيين (Environment Variables) في إعدادات مشروع Vercel:

| الاسم | من أين | ملاحظة |
|---|---|---|
| `SUPABASE_URL` | Supabase → Project Settings → API → Project URL | غير حساس |
| `SUPABASE_SERVICE_ROLE_KEY` | نفس الصفحة → service_role | **سرّي جداً — لا يُشارك أبداً** |

كلاهما يُضافان من داخل Vercel مباشرة (Settings → Environment Variables)، وليس من ملف `.env` مرفوع مع الكود.

## ما لم يُنجز بعد في هذه النسخة (بوضوح)

- **ملفات الحصاد والمراجع (PDF)**: الروابط المخزَّنة في قاعدة البيانات حالياً نسبية
  (مثل `./files/2026-08/W1/harvest.pdf`) وتفترض وجود مجلد `files/` بجانب الموقع، تماماً كما
  في النسخة الحالية على Vercel. في هذا الإصدار الأول، **لم تُرفع هذه الملفات بعد** لتفادي رفع 68
  ميجابايت دفعة واحدة عبر واجهة GitHub — سنضيفها في خطوة لاحقة منفصلة بعد التأكد أن الأرقام
  والنصوص تعمل بشكل صحيح أولاً.
- لا توجد صفحة إدارة (Admin) بعد — هذه مرحلة قادمة منفصلة تماماً.

## لا شيء هنا يمسّ المشروع الحالي على Vercel

هذا مشروع Vercel جديد ومنفصل بالكامل عند نشره — لن يستبدل أو يعدّل أو يتصل بأي شكل بالمشروع
الحالي الذي تستخدمه شيماء.
